# Methodology

The broad problem is choosing an agent's next action. The experiments deliberately restrict that action set: weak answer, strong answer, validation of a weak answer, and conditional escalation. Human review is an expectation model, never measured human behaviour.

E0 retained basic success/error instrumentation evidence; its original module-level paid-call script is intentionally omitted. The compact evidence supports inspection of four exact-response successes and one invalid-model failure, not replay of provider HTTP responses.

E1 uses the frozen procurement policy and exact-set scoring. Order and duplicate controls do not change historical set equality; schema validity remains separate. Terminal prohibition, threshold inclusivity and exception precedence must not be reinterpreted. Public tests include the original policy assertions and an independently encoded policy table across3840 combinations.

E2 evaluates actual validators on frozen E1 weak answers. PASS retains weak output; FAIL selects the paired frozen strong output. Oracle truth scores decisions but never selects the observed routing branch. Three validator repetitions attach to each of270 sources, not810 independent tasks.

E3 uses36 profiles: D in(.25,.5,.75,1), C in(.5,.75,1), F in(0,.05,.15). Expected reviewed correctness is p(1-F)+(1-p)DC. D/C/F are hypothetical probabilities. Economics uses frozen API estimates plus equal assumed error loss L and review cost H. Stage2c retains the1e-12 tolerance and route ordering. Strong-error sensitivity holds weak outputs, validator decisions and costs fixed; one source perturbation is shared across roles/repetitions.

EX1 prospectively selected60 new model-blind cases,10 per structural stratum, using seed20261019 and deterministic SHA-ranked selection. Candidate pool, selected cases, oracle and180 renderings are included. The population differs from E1 and is not silently pooled. Both solver calls and both validator calls were collected per rendering; cascades are reconstructed afterward.

Weak-only and strong-only charge their one solver call. A validator cascade charges weak+validator+paired strong only on FAIL. Strong validation and strong solution are distinct calls. Cost/correct divides all resolved route costs by correct results; it is not unconditional operational cost/correct.

Frozen USD/million normalized input and output-plus-thought tariffs: weak0.30/2.50; strong0.75/3.75. Invocation-level counters are never added. These conventions reproduce research estimates, not invoices or current tariffs.
